# Yusuf Utkan's Portfolio Website

## Overview

This is a multi-page personal portfolio website presenting Yusuf Utkan's background as a computer science student, skills, projects, and resume.

## Features

- Navigate between the Home, About, Skills, Projects, and Resume pages.
- Review project descriptions and open available calculator and pizza-order demos.
- Follow links to the project's GitHub repositories.
- View education, experience, and activities, and download a resume PDF.
- Contact links include GitHub, LinkedIn, and email.

## Technologies Used

- **HTML** — site content and navigation.
- **CSS** — page presentation and layout.
- **JavaScript** — calculator and pizza-order demonstrations.
- **Font Awesome** — icons loaded from cdnjs.

## Getting Started

Preview the live site: [https://yusufthecoder02.github.io/Portfolio-Website/](https://yusufthecoder02.github.io/Portfolio-Website/)

To run it locally, clone or download the repository and open `index.html` in a web browser. The site is made up of static browser files; the repository contains no package manifest or build configuration.


## How It Works

The top-level HTML files provide the portfolio pages. They link to local stylesheets under `css/`. The project demonstrations are in `demos/` and use client-side JavaScript. The resume page links to a PDF in `assets/`. Font Awesome is loaded from an external CDN.

## Project Structure

```text
Portfolio-Website/
├── index.html        # Home page
├── about.html        # About page
├── skills.html       # Skills page
├── projects.html     # Project listings and demo links
├── resume.html       # Resume information and PDF download
├── css/              # Site stylesheets
├── demos/            # Calculator and pizza-order demonstrations
├── assets/           # Resume and other site assets
├── images/           # Visual assets
└── fonts/            # Fonts
```

## Limitations

The demonstrations run in the browser and do not submit orders or connect to a backend service. No deployment URL or build configuration is included in the repository.
